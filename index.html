Introduction

Every time you open a web page, your device sends an HTTP request and a server sends back an HTTP response. HTTP (Hypertext Transfer Protocol) is the set of rules that browsers and servers use to talk to each other.

This site looks at HTTP as one of the core technologies of the World Wide Web. It explains what HTTP does, how requests and responses are built, and why the protocol exists. It then follows the history of HTTP from the one-line HTTP/0.9 in 1991 to HTTP/3 in 2022.

The main idea is that the meaning of HTTP (methods like GET and POST, status codes like 404, and headers) has stayed almost the same for 30 years, while the way messages travel across the network has been redesigned several times to make the web faster and safer.
